# THE MUSIC HYPEE

Website for THE MUSIC HYPEE, a music marketing agency that grows artists on Spotify, YouTube, Instagram, SoundCloud and Apple Music.

It is a single static page, `index.html`, with a black-and-white 3D design:

- 3D logo (three.js) with a glowing spectrum ring that pulses to a beat, plus an optional synthesized soundtrack
- Services, the platforms we grow, and a release-cycle timeline
- Campaign results with case-study charts
- Testimonials in a draggable 3D carousel
- Contact through Instagram DM: visitors write a message with their track link, it is copied for them, and the button opens a DM with [@themusichypee](https://www.instagram.com/themusichypee/) via `https://ig.me/m/themusichypee`

## Run it

Open `index.html` in a browser, or publish it with GitHub Pages (Settings → Pages → deploy from the `main` branch). Fonts and libraries load from Google Fonts, cdnjs, jsDelivr and unpkg, so it needs an internet connection.

## Before going live

The campaign numbers, case studies and testimonials are sample content. Replace them with real results and client quotes.
